# BOJ 2961 - 도영이가 만든 맛있는 음식

## 문제 설명
N개의 재료가 주어지고, 각 재료는 신맛(S)과 쓴맛(B)을 가진다.
요리의 신맛은 사용한 재료의 신맛의 곱이고, 쓴맛은 사용한 재료의 쓴맛의 합이다.
최소 1개 이상의 재료를 사용하여 신맛과 쓴맛의 차이를 최소화하는 문제.

## 입력
- 첫째 줄: 재료의 개수 N (1 ≤ N ≤ 10)
- 둘째 줄부터 N개 줄: 각 재료의 신맛 S와 쓴맛 B (1 ≤ S, B ≤ 1,000,000,000)

## 출력
신맛과 쓴맛의 차이의 최솟값

## 접근 방법
1. 재료를 1개~N개까지 선택하는 모든 조합을 확인 (브루트포스)
2. `itertools.combinations`를 사용하여 각 개수별 조합 생성
3. 각 조합마다 신맛(곱)과 쓴맛(합)을 계산
4. 차이의 절댓값의 최솟값 갱신

## 시간 복잡도
- 모든 부분집합 탐색: O(2^N)
- N ≤ 10이므로 최대 1024가지 조합

## 주요 개념
- 조합 (Combinations)
- 브루트포스 (완전탐색)
- `itertools.combinations`
