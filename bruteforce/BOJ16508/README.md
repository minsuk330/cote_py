# BOJ 16508 - 전공책

## 문제 링크
https://www.acmicpc.net/problem/16508

## 문제 요약
- 특정 단어를 만들기 위해 필요한 책들을 구매하는 최소 비용 구하기
- 각 책은 가격과 제목(문자들)을 가지고 있음
- 책 제목의 문자들을 사용하여 목표 단어를 만들 수 있어야 함
- 같은 책을 여러 번 살 수 없음

## 접근 방법

### 1. 브루트포스 (DFS - 부분집합 탐색)
- 각 책에 대해 "선택함/선택 안 함" 두 가지 경우를 모두 탐색
- 시간복잡도: O(2^n)
- n개의 책이 있을 때 모든 부분집합 확인

### 2. 핵심 로직
```python
def dfs(idx, char_check, cur_price):
    # 1. 완성 체크 (모든 필요한 문자를 모았는지)
    # 2. 가지치기 (현재 가격이 최소값보다 크면 중단)
    # 3. 범위 체크 (모든 책 확인 완료)
    # 4. 선택 안 함: dfs(idx+1, char_check, cur_price)
    # 5. 선택함: dfs(idx+1, new_char_check, cur_price+price)
```

### 3. 주의사항
- `char_check`를 복사(dict())해서 백트래킹 구현
- 책의 모든 문자를 순회하며 개수 차감
- 완성 체크를 idx 범위 체크보다 먼저 수행

## 다른 풀이

### BFS
- 큐를 사용하여 너비 우선 탐색
- 메모리 사용량이 많아 DFS가 더 효율적

### 비트마스킹
- 2^n가지 조합을 비트로 표현
- for문으로 0부터 2^n-1까지 순회

## 시간복잡도
- O(2^n × m): n=책의 수, m=평균 책 제목 길이

## 공간복잡도
- DFS: O(n) - 재귀 깊이
- BFS: O(2^n) - 큐에 저장되는 상태
