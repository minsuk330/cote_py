# BOJ 18312 - 시각

## 문제 정보
- **난이도**: 브론즈
- **분류**: 브루트포스, 구현
- **링크**: https://www.acmicpc.net/problem/18312

## 문제 설명
00시 00분 00초부터 N시 59분 59초까지의 모든 시각 중에서 K가 하나라도 포함되는 모든 시각의 개수를 구하는 문제입니다.

### 입력
- 첫 번째 줄: 정수 N과 K (0 ≤ N ≤ 23, 0 ≤ K ≤ 9)

### 출력
- 00시 00분 00초부터 N시 59분 59초까지 K가 하나라도 포함되는 모든 시각의 개수

## 접근 방법
1. 0시부터 N시까지, 0분부터 59분까지, 0초부터 59초까지 3중 반복문으로 모든 시각을 확인
2. 각 시각을 문자열로 변환할 때 **2자리 형식(00~59)**으로 변환
3. 해당 시각 문자열에 K가 포함되어 있는지 확인
4. 포함되어 있으면 카운트 증가

## 주요 포인트
- **시간 형식**: 한 자리 숫자를 두 자리로 표현해야 함 (예: 3 → 03)
- **범위**: N시 59분 59초까지 포함하므로 `range(N+1)` 사용

## 배운 점

### Python 문자열 포맷팅 방법

숫자를 2자리 문자열로 변환하는 여러 방법:

**1. f-string 포맷팅 (Python 3.6+) - 추천!**
```python
h, m, s = 3, 14, 5
time_str = f"{h:02d}{m:02d}{s:02d}"  # "031405"
```
- `:02d` 의미: `0`(0으로 채움) + `2`(2자리) + `d`(정수)
- 가장 간결하고 읽기 쉬움

**2. zfill() 메서드**
```python
time_str = str(h).zfill(2) + str(m).zfill(2) + str(s).zfill(2)  # "031405"
```
- 문자열을 지정한 길이만큼 0으로 채움

**3. format() 메서드**
```python
time_str = "{:02d}{:02d}{:02d}".format(h, m, s)  # "031405"
```

**4. % 포맷팅 (옛날 방식)**
```python
time_str = "%02d%02d%02d" % (h, m, s)  # "031405"
```

**5. 조건문으로 직접 처리**
```python
time_str = (str(h) if h >= 10 else '0'+str(h)) + \
           (str(m) if m >= 10 else '0'+str(m)) + \
           (str(s) if s >= 10 else '0'+str(s))
```
- 코드가 길고 복잡함, 비추천

## 시간 복잡도
- O(N × 60 × 60) = O(N × 3,600)
- N ≤ 23이므로 최대 약 82,800번의 연산
